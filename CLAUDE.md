# Travel app instructions

For any travel plan, PRD, itinerary, place-research, map, menu, or destination-folder request, activate the project skill `.claude/skills/travel-map-builder/SKILL.md` and follow the canonical workflow it references at `.agents/skills/travel-map-builder/SKILL.md`. For UI-only changes, activate `.claude/skills/travel-ui/SKILL.md` and follow `.agents/skills/travel-ui/SKILL.md`. Read `README.md`, `AGENTS.md`, the relevant design/component contract, and `references/research-packet.md` when relevant. For research-only work, use the Claude Code prompt in the README, use the available web search/page-opening tools on source pages rather than snippets, return `travel-research.v1` JSON without editing the app, preserve uncertainty and source URLs, and do not publish. Use the shared `src/travel-ui/` components; keep data in `travel/<destination-slug>/trip.json` and entries in `page/<destination-slug>/index.html`; verify the mobile app; and publish only when the user explicitly asks.
