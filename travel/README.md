# 여행 데이터 보관소

새 여행은 이 폴더 아래에 `destination-slug/`를 만들고 `index.html`과 `trip.json`을 함께 보관합니다.

GitHub Pages 빌드는 이 정본 데이터를 기존의 `/<destination-slug>/` 주소로 출력합니다. 따라서 저장소에서는 여행 폴더가 `travel/` 아래에 모이고, 공개 주소는 기존 규칙을 유지합니다.

기존 루트의 `kyoto-kobe-trip/`와 `jeju-sports-trip/`는 이미 공유된 로컬·Pages 주소를 위한 호환 엔트리입니다. 여행 데이터는 이 폴더의 JSON만 수정합니다.
